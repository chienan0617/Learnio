## 🔑 核心功能

### LevelMapPage（主容器）

```
┌─────────────────────────────────┐
│  🗺️ 關卡地圖  [📍] [⬅️]        │ ← _buildTopBar() 毛玻璃效果
├─────────────────────────────────┤
│                                 │
│        [⭐ 08]  ← 當前關卡      │
│       /        \                │
│    [07]        [09]  ← 已解鎖 │
│     /                           │
│  [06]           [10] ← 未解鎖  │
│                                 │
│  ... 無限滾動加載 ...           │
│                                 │
└─────────────────────────────────┘
```

### 組件樹

```
LevelMapPage
├── Stack
│   ├── 背景容器 (漸層)
│   ├── ListView.builder (無限滾動)
│   │   └── LevelRow (每一行)
│   │       ├── CustomPaint (_LevelPathPainter)
│   │       └── LevelBubble (個別氣泡)
│   └── TopBar (毛玻璃 + 導航)
```
