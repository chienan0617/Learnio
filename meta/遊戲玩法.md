# Infinite Mix - 遊戲玩法指南

## 🎮 遊戲概覽

**Infinite Mix** 是一款不斷發現和創造新元素的無限混合遊戲。玩家通過將不同的元素進行組合，創造出全新的元素，逐步解鎖更多可能性。

**遊戲目標**：探索無限的元素組合，發現新元素，達到最高的"煉金師"級別。

---

## 🎯 核心遊戲機制

### 1. **元素系統 (Element System)**

遊戲基於**元素**的概念運作。每個元素具有以下屬性：

- **名稱**: 元素的識別名稱
- **顏色**: 視覺上的獨特顏色
- **創建時間**: 元素首次發現的時間
- **編輯次數**: 元素被修改的次數
- **特殊標籤**: 標記為"特殊"的稀有元素

#### 起始元素 (Seed Elements)

遊戲開始時，玩家會在無限畫布上獲得 6 個種子元素：

- **新** (紅色)
- **春** (琥珀色)
- **大** (青綠色)
- **禮** (藍色)
- **包** (紫色)
- **💩** (棕色)

這些元素不能被刪除，作為創造任何其他元素的基礎。

---

### 2. **無限畫布 (Infinite Canvas)**

**主要互動空間**，允許你放置和管理元素。

#### 畫布特性：

- **大小**: 10,000 × 10,000 像素的無限工作區
- **網格背景**: 提供視覺參考
- **縮放和平移**:
  - 使用兩指或滑鼠滾輪縮放 (0.1x - 3.0x)
  - 拖動平移畫布
- **自動居中**: 可以一鍵將視圖重新居中到畫布中心

---

### 3. **元素放置 (Element Placement)**

#### 從元素庫添加元素

1. 點擊底部的 **「庫」** 按鈕打開元素庫
2. 瀏覽已發現的元素
3. 點擊任意元素將其添加到畫布
4. 新元素會在隨機位置生成

#### 複製元素

- **長按元素** → 在相鄰位置生成該元素的副本

---

### 4. **複製元素的兩種方式**

#### 方式 1：單一合成 (Single Combine)

1. **拖動**一個元素到另一個元素上方
2. **自動檢測接近**：兩個元素在 90 像素内會自動觸發合成
3. 系統會暫時閃爍兩個元素以視覺反饋
4. 發送到伺服器 API 計算結果
5. 合成結果會在兩個元素的交匯點生成

#### 方式 2：多元素合成 (Multi-Mix)

1. 通過右側側面板識別 **✨ 混合區**（帶有「✨」圖標的區域）
2. **拖動多個元素** (2 個或更多) 到混合區
3. 進入"等待合成"狀態
4. 系統同時發送所有元素到 API
5. 結果在畫布中心生成

#### 方式 3：長按快速複製

- **長按** 任意元素生成副本（無需合成）

---

### 5. **元素刪除 (Element Deletion)**

#### 清空單一元素

1. 識別右側側面板上的 **🗑️ 垃圾桶** 區域
2. **拖動元素**到垃圾桶區域
3. 鬆開時元素會被刪除

#### 批量刪除

- 在元素庫中進入"編輯模式"
- 選擇非初始元素點擊刪除
- 會從庫和畫布上同時刪除

---

### 6. **合成與發現 (Combination & Discovery)**

#### 合成流程

1. 將「元素 A」和「元素 B」在畫布上放在一起
2. 自動檢測或手動拖動觸發
3. 系統發送組合請求到遠程 API (`https://cas.cas617.workers.dev/infiniteMix/getResult`)
4. API 返回：
   ```json
   {
     "result": "新元素名",
     "color": "#RRGGBB",
     "special": false
   }
   ```

#### 首次發現獎勵

- 如果元素是首次發現，它會添加到**元素庫**
- 玩家會收到"{名稱} 已新增"的確認提示
- 元素計數和進度會更新

#### 已知元素重複

- 如果合成出已知元素，顏色會更新但不算新發現
- 元素位置仍會生成結果物體

#### 特殊元素

- 某些合成結果會標記為**特殊元素**
- 可在元素庫中篩選查看
- 通常代表稀有或獨特的組合

## 📊 進度與排名系統

### 級別系統

**級別**基於發現的元素數量計算：

```
級別 = (發現元素數 / 10) + 1
```

#### 級別等級和稱號

| 級別範圍 | 稱號       | 描述                   |
| -------- | ---------- | ---------------------- |
| 1-2      | 見習學徒   | 每一次嘗試都是進步     |
| 3-4      | 初級煉金師 | 開始掌握融合之道       |
| 5-9      | 元素收藏家 | 收集更多，發現更多     |
| 10-19    | 資深探索者 | 探索永無止境           |
| 20-29    | 大師煉金師 | 掌握元素的奧秘         |
| 30-49    | 傳奇合成者 | 融合的極致，創造的巔峰 |
| 50+      | 宇宙煉金師 | 萬物即是你的實驗室     |

### 進度條

- **下一級所需**: 級別 × 10 個元素
- **當前進度**: (已發現元素數 ÷ 下一級所需) × 100%

## 📖 元素庫 (Library)

### 功能概覽

開啟全屏書籍式界面展示所有元素。

### 搜索功能

- **實時搜索**: 在搜索欄輸入元素名稱
- **即時篩選**: 自動匹配包含搜索詞的元素

### 分類篩選

| 分類     | 說明                       |
| -------- | -------------------------- |
| **全部** | 顯示所有已發現元素         |
| **最新** | 按創建時間新到舊排序       |
| **色系** | 按色調 (HSV Hue) 排序      |
| **特殊** | 隻顯示帶有"特殊"標籤的元素 |

### 元素卡片

每個元素卡片顯示：

- **顏色塊**: 元素的視覺顏色表示
- **名稱**: 元素識別名稱
- **操作**:
  - **點擊**: 將元素添加到畫布
  - **長按**: 編輯元素（如適用）

### 編輯模式

- 點擊"編輯"按鈕進入編輯模式
- 選擇任何非初始元素
- **長按刪除確認**: "確定要永久刪除... 嗎？"
- 從庫和畫布上同時移除

### 分頁

- 每頁顯示 50 個元素
- 底部分頁控制
- 搜索或篩選會重置頁碼

## 👤 個人檔案頁面 (Profile Page)

### 顯示信息

#### 玩家統計

- **當前級別**: 基於發現元素數

#### 進度條

- 視覺進度條顯示升級進度
- 百分比顯示進度

### 分享功能

- 分享當前遊戲進度到社交媒體
- 包含等級、元素數量等摘要

## 💾 數據存儲與位置 (Storage & Locations)

### 多個位置 (Storage Locations)

遊戲支持多個獨立的遊戲世界/位置：

- **位置 ID**: 整數標識符（0, 1, 2, ...）
- **隔離存儲**: 每個位置有自己的元素和畫布項目
- **位置切換**: 通過頂部存儲欄選擇不同的世界

### 本地存儲

使用 **Hive CE** (Hive Community Edition) 數據庫：

- 高效的本地鍵值存儲
- 離線功能完全支持
- 快速讀寫性能

#### 存儲的數據類型

1. **MixElementData** (Type ID: 50)
   - 元素定義
   - 顏色、名稱、時間戳
   - 特殊標籤

2. **CanvasItemData** (Type ID: 51)
   - 元素實例（放在畫布上）
   - 位置 (dx, dy)
   - 縮放

## 🌐 後端 API 集成

### 合成端點 (Combine Endpoint)

**基礎 URL**: `https://cas.cas617.workers.dev/infiniteMix/getResult`

#### 請求格式

```http
GET /infiniteMix/getResult?e=element1,element2,element3
```

#### 查詢參數

- `e`: 逗號分隔的元素名稱列表

#### 響應格式

```json
{
  "result": "新元素名稱",
  "color": "#RRGGBB",
  "special": false
}
```

#### 響應字段

- **result** (string): 合成後的新元素名稱
- **color** (hex string): 新元素的顏色代碼
- **special** (boolean): 是否為特殊/稀有元素

#### 錯誤處理

- 無效響應拋出異常
- 缺少必需字段時中止
- HTTP 錯誤代碼會記錄

## ⚙️ 高級功能

### 交互功能

#### 拖動機制

1. **按下** → 選中元素並鎖定
2. **拖動** → 實時更新位置
3. **釋放** → 檢測碰撞和合成

#### 檢測區域

- **自動合成**: 兩個元素相距 ≤ 90 像素
- **垃圾桶區**: 檢測拖動的元素邊界
- **混合區**: 檢測多元素區域

#### 視覺反饋

- **選中時縮放**: 拖動時元素放大 1.1x
- **懸停效果**: 邊界高亮、顏色變化
- **合成閃爍**: 合成進行時交替閃爍
- **加載指示器**: 等待 API 響應時居中顯示

### 色彩管理

#### 元素色彩顯示

- 保底最低不透明度 0.15（防止隱形）
- 自動計算樂觀度以選擇黑色/白色文字
- 支持完整 RGBA 顏色

#### 自訂元素顏色

1. 點擊"添加元素"按鈕
2. 打開顏色選擇器
3. 選擇顏色和透明度
4. 輸入名稱
5. 確認創建

| **GameController**    | 管理遊戲邏輯、合成、級別 |

## 🌟 提示與技巧

### 高效探索

1. 從簡單組合開始
2. 系統地結合已有元素
3. 對 API 返回的結果進行實驗
4. 追踪特殊元素發現

### 優化畫布

1. 使用垃圾桶清理不需要的項目
2. 利用縮放/平移查看大量元素
3. 按色系分類組織元素
4. 使用搜索快速定位元素

### 級別進度

- 每發現 10 個新元素升級一級
- 重複組合沒有新進度收益
- 專注於多元素合成發現新組合
- 加入多元素混合量加快探索速度

---

## 📝 注意事項

- **初始元素不可刪除**: 6 個種子元素是永久的
- **離線遊戲**: 所有數據本地存儲，無需互聯網（除合成 API）
- **數據持久化**: 所有進度自動保存
- **多位置獨立**: 不同位置的元素互不影響
- **合成 API 依賴**: 需要互聯網連接才能執行合成操作
